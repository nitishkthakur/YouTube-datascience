# Fonts

Installed system-wide via Homebrew casks (all SIL Open Font License):

    brew install --cask font-inter font-jetbrains-mono font-stix-two-math font-stix-two-text

Manim's `Text` (Pango) and XeLaTeX both find system fonts, so nothing is vendored here.
Names are referenced only from `src/dsanim/palette.py`.
